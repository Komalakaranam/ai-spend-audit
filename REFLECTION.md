# Project Reflection

## Overview

This project evolved from a simple frontend audit calculator into a full-stack SaaS-style application with persistent storage, dynamic routing, and shareable audit reports.

The goal was not only to build functional features, but also to simulate the rapid iteration style commonly used in startup MVP development.

---

# Key Learnings

## Full-Stack Integration

One of the most valuable parts of the project was learning how frontend applications connect with cloud databases using Firebase Firestore.

This included:
- saving documents
- fetching reports dynamically
- handling asynchronous operations
- debugging Firestore permissions
